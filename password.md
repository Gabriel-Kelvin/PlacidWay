# Admin password

The admin password is configured privately as `ADMIN_PASSWORD` in the Render service environment. Use the existing password supplied by the project owner to sign in at:

https://placidway-care-navigator.onrender.com/admin

This repository is public. The actual password is deliberately omitted so visitors cannot access the admin workspace. Do not commit `.env`, the Supabase server key, the Groq key, or the session signing secret.
